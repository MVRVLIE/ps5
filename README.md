# Формула симпатии

Мобильная новелла-мессенджер. Ника готовится к экзамену по матану и пишет тебе;
ты помогаешь ей с примерами, растёт симпатия, она присылает фото — они собираются
в галерею. Полностью на HTML5 + Canvas-free SVG, без движка, без зависимостей,
без единого внешнего ассета: вся графика и весь звук генерируются кодом.

```
npm start        # → http://localhost:8080
npm test         # смоук-тест: прогоняет сюжет целиком в headless-браузере
```

Открывать на телефоне или в мобильном режиме девтулзов — игра портретная.

## Что внутри петли

**Одна сессия** = глава: 8–15 сообщений, 2 примера, 2 фото, 3 выбора реплики.
Примерно 4 минуты. Шесть глав — около 25 минут контента, дальше свободный режим.

**Ядро.** Ника пишет → присылает пример → 4 варианта ответа → верный ответ даёт
симпатию, неверный — разбор решения. Тупиков нет: сюжет едет дальше при любом
ответе, ошибка стоит только симпатии. Это важно — новелла не должна упираться
в математику.

**Что удерживает**

| Механика | Где | Зачем |
|---|---|---|
| 10 уровней симпатии | шапка чата | видимая полоска, до следующего уровня всегда близко |
| Коллекция из 12 фото | вкладка «Галерея» | пустые слоты с подписью «глава 4» — видно, чего не хватает |
| Серия верных ответов | карточка примера | с 3-й подряд +60% симпатии — «ещё один» |
| Серия дней | профиль | заход в новый день = счётчик, пропуск = сброс |
| Челлендж дня | конец главы | 5 примеров, у всех в этот день одинаковые (общий сид от даты) |
| Крючок в конце главы | «завтра будет хуже: дроби» | явный анонс следующей сессии |
| Свободный режим | после финала | контент кончился — игра нет; ведётся лучшая серия |
| 11 достижений | профиль | добивание для тех, кто прошёл сюжет |

**Почему это форсится в TikTok.** Экран выглядит как настоящая переписка —
клип не нужно объяснять, он читается с первого кадра. Формат ролика:
«она кидает пример → пауза 2 секунды → ответ → её реакция и фото».
Зритель считает в уме вместе с автором и досматривает до конца ради реакции.
Комменты собираются сами: неверный ответ в клипе = сотня «поправляющих».
Челлендж дня даёт повод спорить — у всех сегодня одни и те же 5 примеров.

Контент осознанно SFW: фото — рисованные иллюстрации, история — про
«помог с матаном и понравился». Это проходит модерацию TikTok, App Store
и Google Play; вариант «пикап-новелла со сливами» не проходит нигде и
живёт ровно до первой жалобы.

## Устройство

```
index.html            три экрана (чат / галерея / профиль) + оверлеи
styles.css            вся вёрстка; тёмная палитра, safe-area, prefers-reduced-motion
src/
  main.js             сборка: вкладки, галерея, профиль, лайтбокс, тосты, PWA
  chat.js             движок переписки — сердце игры
  story.js            сценарий: 6 глав, 81 шаг (только данные, без логики)
  math.js             11 генераторов примеров + правдоподобные неверные варианты
  art.js              вся графика: параметрический портрет + 6 сцен, SVG-строками
  gallery.js          каталог фото и сетка коллекции
  state.js            localStorage: симпатия, главы, стрики, коллекция
  audio.js            WebAudio: ноты синтезируются, аудиофайлов нет
sw.js                 офлайн-кэш; manifest.webmanifest — установка на домашний экран
server.js             статик-сервер без зависимостей
test/smoke.mjs        прогон всей игры в браузере: сюжет, галерея, сохранение
```

**Движок переписки.** Каждый интерактивный шаг — `await` промиса, который
резолвится тапом игрока, поэтому весь сценарий читается сверху вниз:

```js
const opt = await showReplies(st.opts);   // ждём выбор реплики
await me(opt.x);                          // отправляем её от игрока
await gain(opt.aff);                      // симпатия + возможный level-up
await her(opt.reply);                     // ответ Ники с «печатает…»
```

Прогресс пишется после каждого шага, последние 40 реплик хранятся в
`state.log` — при возврате чат не пустой, как в настоящем мессенджере.

**Примеры.** `makeProblem(topic, difficulty)` отдаёт вопрос, ответ, разбор и
4 варианта. Неверные варианты — не случайный шум, а типичные ошибки
(`(8x²)′` → `8x`, «сложил числители и знаменатели»), поэтому промах учит.
Темы подключаются по уровню симпатии: арифметика → дроби → уравнения →
квадратные → прогрессии → производные → интегралы → пределы.

**Графика.** `portrait({expr, bg, outfit, accessory})` — один генератор на все
портреты: 6 выражений лица, 4 аксессуара, любые цвета. Плюс 6 нарисованных
сцен. Итого 12 карточек коллекции без единого файла картинки.

## Как расширять

**Добавить главу** — дописать объект в `CHAPTERS` (`src/story.js`).
Шаги: `sys` `msg` `me` `choice` `math` `photo` `end`. Логику трогать не нужно.

**Добавить фото** — новая запись в `PHOTOS` (`src/gallery.js`) + шаг
`{ t: 'photo', id: '…' }` в сценарии. Портрет собирается параметрами,
рисовать ничего не надо.

**Добавить тему примеров** — генератор в `G` (`src/math.js`), подпись в `TOPICS`,
подключение в `topicsForLevel`.

## Упаковка в сторы

Это PWA — ставится на домашний экран как есть. Для нативной сборки:

```bash
npm i -D @capacitor/cli @capacitor/core @capacitor/android @capacitor/ios
npx cap init "Формула симпатии" com.example.formula --web-dir=.
npx cap add android && npx cap add ios
npx cap sync
```

`webDir` — корень репозитория, сборка не нужна: файлы уже статические.
