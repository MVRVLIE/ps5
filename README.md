# «Девятка» — блок-пазл 9×9 для Яндекс Игр

Готовая к публикации HTML5-игра: перетаскивайте фигуры на поле 9×9, собирайте
строки, столбцы и квадраты 3×3, набирайте комбо. Полностью интегрирована с
Yandex Games SDK v2 — лидерборд, реклама, облачные сохранения, локализация.

**Без зависимостей.** Ни одного пакета из npm: ES-модули работают в браузере
напрямую, сборщик и генератор графики написаны на голом Node.
Собранный архив — около **110 КБ**.

```
npm run dev      # локальный запуск: http://localhost:8080
npm test         # тесты игровой логики (20 проверок)
npm run assets   # перегенерировать иконку и обложку
npm run build    # dist/ + build/nine-block-puzzle-v1.0.0.zip для загрузки
```

## Что уже сделано

**Геймплей**
- Поле 9×9, три фигуры в лотке, 16 семейств фигур со всеми поворотами.
- Очистка строк, столбцов и квадратов 3×3 за один ход, комбо-множитель до ×3.
- Бонус +150 за полностью очищенное поле.
- Честная раздача: пока поле свободно, заведомо мёртвый набор не выдаётся;
  на плотном поле раздача обычная, иначе игра никогда бы не заканчивалась.
- Перетаскивание мышью и пальцем, подсветка линий, которые соберутся,
  подсказка о недопустимой позиции, на сенсоре фигура приподнимается над пальцем.
- Частицы, анимации, тряска поля, всплывающие очки, звук (Web Audio, без файлов).
- Пауза, продолжение незаконченной партии после перезагрузки.

**Интеграция с платформой (`src/platform/yandex.js`)**

| Возможность | Как используется |
|---|---|
| `YaGames.init()` | старт, с таймаутом 8 с — SDK не может заблокировать загрузку |
| `LoadingAPI.ready()` | вызывается, когда игра готова к вводу |
| `GameplayAPI.start/stop()` | начало и конец активного геймплея, пауза, реклама |
| `adv.showFullscreenAdv()` | межстраничная реклама между партиями, свой кулдаун 90 с |
| `adv.showRewardedVideo()` | «Спасение» после проигрыша, до 2 раз за партию |
| `adv.showBannerAdv()` | липкий баннер (выключен, включается в `config.js`) |
| `getPlayer()` + `getData/setData` | облачные сохранения с троттлингом и слиянием с локальными |
| `getLeaderboards()` | отправка счёта и таблица лидеров с аватарами |
| `auth.openAuthDialog()` | вход из экрана лидеров |
| `shortcut` | предложение ярлыка на рабочий стол после 2-й партии |
| `feedback` | просьба оценить игру после хорошего рекорда |
| `environment.i18n.lang` | автовыбор языка |
| `deviceInfo` | определение мобильного устройства |

Все вызовы SDK обёрнуты: вне платформы игра просто работает в локальном режиме
(сохранения в `localStorage`, награда за рекламу выдаётся сразу для отладки).

**Локализация** — русский, английский, турецкий; язык берётся из SDK, его можно
переключить вручную в меню.

**Адаптив** — портрет (поле сверху, лоток снизу) и ландшафт (поле слева, лоток
колонкой справа), учёт `safe-area`, DPR до 2.5×, тёмная тема.

## Публикация на Яндекс Играх

1. **Соберите архив**

   ```
   npm run assets   # если ещё не генерировали картинки
   npm run build
   ```

   Появится `build/nine-block-puzzle-v1.0.0.zip` — в корне архива лежит
   `index.html`, как того требует платформа. Сборщик сам проверяет, что
   `index.html` на месте, что подключён `/sdk.js` и что в коде нет обращений
   к внешним ресурсам.

2. **Создайте черновик игры** в [консоли разработчика](https://games.yandex.ru/console)
   и загрузите архив на вкладке с файлами игры.

3. **Создайте лидерборд.** В консоли, в разделе лидербордов, добавьте таблицу с
   техническим именем **`score`** (сортировка — по убыванию, тип — целое число).
   Имя должно совпадать с `CONFIG.leaderboardName` в `src/config.js`.
   Без этого экран «Лидеры» покажет сообщение о недоступности рейтинга,
   но игра продолжит работать.

4. **Включите рекламу.** Межстраничные блоки работают сразу; для «Спасения»
   нужен блок с вознаграждением. Если rewarded-реклама недоступна, кнопка
   спасения честно сообщит об этом и не сломает партию.

5. **Заполните карточку игры:**
   - иконка — `assets/icon-512.png` (512×512);
   - обложка — `assets/cover-800x470.png` (800×470);
   - название, описание и теги — на русском и английском;
   - категория: головоломки; управление: мышь и сенсор.

   Актуальные требования к размерам изображений всегда указаны в самой консоли —
   сверьтесь с ней перед загрузкой.

6. **Отправьте на модерацию.**

### Чек-лист перед отправкой

- [x] `index.html` в корне архива
- [x] подключён `<script src="/sdk.js">`
- [x] вызывается `LoadingAPI.ready()`
- [x] нет загрузок с внешних доменов (проверяется при сборке)
- [x] звук глушится на время рекламы и при уходе вкладки в фон
- [x] игра корректно работает и в портрете, и в ландшафте
- [x] есть русская локализация
- [ ] лидерборд `score` создан в консоли
- [ ] блок rewarded-рекламы создан в консоли
- [ ] иконка и обложка загружены

## Настройка

Почти всё, что стоит менять, собрано в [`src/config.js`](src/config.js):

```js
leaderboardName: 'score',   // техническое имя лидерборда из консоли
maxRescues: 2,              // спасений за рекламу в одной партии
interstitialCooldownMs: 90_000,
interstitialAfterGames: 1,  // не показывать рекламу до N-й партии
stickyBanner: false,        // липкий баннер
shortcutAfterGames: 2,      // когда предложить ярлык
reviewAfterScore: 400,      // с какого счёта просить оценку
colors: [...],              // палитра блоков
score: { perCell, lineBase, comboStep, comboMax },
```

Сложность регулируется весами фигур в `src/game/pieces.js` (`weight` у каждого
семейства) и порогом честной раздачи `fairLimit` в `dealTray`.

### Как переименовать игру

Название берётся из локализаций: ключи `app.title` и `app.subtitle` в
`src/i18n/index.js`, плюс `<title>` в `index.html` и `name` в `package.json`.

### Как добавить язык

В `src/i18n/index.js` скопируйте блок `en`, переведите значения (ключи менять
нельзя) и добавьте язык в `LANGS`. Тест `npm test` проверит, что ни один ключ
не забыт. Кнопка языка в меню появится автоматически.

## Структура

```
index.html              разметка, экраны меню и подключение SDK
src/
  config.js             все настройки игры
  main.js               связывает логику, отрисовку, звук, интерфейс и SDK
  styles.css            тёмная тема, адаптив, safe-area
  core/                 ГПСЧ и утилиты цвета
  game/
    board.js            поле 9×9, поиск и очистка линий
    pieces.js           фигуры, повороты, раздача
    game.js             счёт, комбо, конец игры, спасение, сохранение партии
    layout.js           раскладка для портрета и ландшафта
    renderer.js         отрисовка на canvas
    input.js            перетаскивание мышью и пальцем
    particles.js        частицы и всплывающие подписи
    audio.js            звук на Web Audio, без файлов
  platform/
    yandex.js           обёртка над Yandex Games SDK v2
    save.js             прогресс: локально + облако, со слиянием
    storage.js          безопасный localStorage
  i18n/index.js         переводы ru / en / tr
  ui/ui.js              экраны, HUD, таблица лидеров
tools/
  serve.mjs             локальный сервер с заглушкой /sdk.js
  build.mjs             сборка dist/ и zip без зависимостей
  make-assets.mjs       генерация иконки и обложки (PNG рисуется кодом)
tests/
  game.test.mjs         тесты логики: node --test
  e2e.mjs               сквозной тест в браузере (нужен Playwright)
```

## Тесты

```
npm test        # 20 проверок логики: очистка линий, счёт, комбо, конец игры,
                # спасение, сохранение/восстановление, полнота переводов

npm i -D playwright && npx playwright install chromium
npm run test:e2e            # сквозной прогон в браузере
SHOTS=./shots npm run test:e2e   # ещё и скриншоты всех экранов
```

Сквозной тест поднимает локальный сервер, играет мышью в трёх разрешениях
(мобильный портрет, десктоп, телефон в ландшафте), проверяет перетаскивание,
очистку линий, экран проигрыша, спасение за рекламу, смену языка и
восстановление партии после перезагрузки, и падает при любой ошибке в консоли.

## Отладка

Откройте игру с параметром `?debug=1` — в `window.__nine` появятся `game`,
`renderer`, `ui`, `platform` и `save`. Без параметра внутренности наружу
не выставляются.
